Actor: Student
Goal: Leave a review describing how effective a tutor was.
Precondition: The student worked with the tutor, and their tutoring session has ended.
Main success scenario
1. The system displays a Review button for the session.
2. The student selects Review.
3. The student writes a review describing how effective the tutor was.
4. The student submits the review.
5. The system records the review.
Extensions
- 1a. The system sends the student a link asking whether they want to leave a review. The student opens the link; continue at step 3.
- 2a. The student does not select Review. The use case ends without a review.
