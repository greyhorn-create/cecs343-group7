## Decision 0004

Add a main page that gives users access to the tutor-search feature. For now, the page will show only this feature.
For now, the page will show only this feature. keep tutor matching in tutor_matching.py and keep /tutors as a JSON endpoint.

Alternative considered: Keep the project as a JSON API with no main page, or build a website containing every planned
feature before releasing it. 

Why we rejected it: A JSON API alone doesn't give students a main page to use. Building every planned feature now would 
add work before those features are ready. A simple page gives the current tutor-search feature a place in the website and
lets the team add other features later. 

Cost of our Decision: We will need to maintain the main page as well as the JSON endpoint, and keep the page's subject,
day, and time fields aligned with the endpoint. We will add pytest coverage for the main page while keeping thests for
JSON responses.
